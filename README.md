## Scratch Week 0 Project

# 🧙‍♂️ Harry Potter Maze (Scratch Project)

A magical maze game inspired by Harry Potter and the Goblet of Fire, where the environment changes dynamically and the player must find the exit (Goblet) while adapting to shifting paths.

---

## 🎮 About the Game

In this project, the player explores a magical living maze. The walls (enchanted vegetation) can change during gameplay, opening and closing paths in real time.

The challenge is to navigate through the maze while reacting to its unpredictable transformations and dangers, using the spell “Finite Incantatem” to undo Krum’s “Confundus” dark magic.

---

## ✨ Main Features

- 🧭 Dynamic maze system using costume changes
- 🧱 Collision detection using a hidden background layer placed behind the visible maze
- 🌿 Living maze that changes during gameplay
- 🧠 Reactive gameplay with shifting paths and Krum’s “Confundus” spell
- 🔄 Five dynamic maze layouts that change every 15 seconds
- 🎵 Win and lose screens with music

---

## 🧩 How the Maze Works

The maze is built using multiple costumes of a single sprite. Each costume represents a different layout of paths.

When the costume changes:

- Some paths open
- Others close
- The player must quickly adapt to the new layout

This creates a constantly evolving maze experience.

---

## 🏁 Objective

- Find your way through the maze while dealing with its changing structure

---

## 🧠 Core Mechanics Used

- Collision detection using a hidden background layer placed behind the visible maze
- Getting stuck while the maze changes its layout until it changes again is part of the challenge in a living maze
- Costume switching system for dynamic environments
- Five dynamic maze layouts that change every 15 seconds
- Win condition detection when the player touches the Goblet
- Win and lose screens with music

---

## 🎨 Inspiration

Inspired by the magical maze from Harry Potter and the Goblet of Fire, where the environment is unpredictable, alive, and constantly shifting.

---

## 📌 How to Play

1. Click the green flag
2. Press **H**
3. Use the arrow keys on your keyboard to move your character
4. Navigate through the maze
5. Pay attention to Cedric’s hints for a better gameplay experience
6. Avoid Krum — encountering him will trigger a lose screen, as he can kill the player
7. Reach the exit 🏁 (Goblet)
